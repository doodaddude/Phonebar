# PhoneBar for macOS

  <img src="Support/AppIcon.png" width="128" height="128" alt="PhoneBar App Icon" style="border-radius: 28px;" />
</p>

A lightweight, liquid glass floating phone interface for macOS. Run your favorite mobile web applications, AI chat interfaces, and camera feeds directly from your menu bar and floating liquid bubbles.

## Features
- **True Liquid Glass UI:** Frosted glass headers, footers, and smooth floating bubble menus.
- **Floating Phone Frame:** Clean mobile viewport with quick switching between popular web apps.
- **Hardware-Accelerated & Low-Latency:** Native WebKit and WebRTC playback.
- **Developer ID Signed:** Pre-signed with Apple Developer ID for macOS Gatekeeper compatibility.

## Installation
1. Download **`PhoneBar-for-mac.zip`** from the [Latest Releases](https://github.com/doodaddude/Phonebar-for-mac/releases).
2. Unzip and drag `PhoneBar.app` into your `/Applications` folder.
3. Open `PhoneBar.app`.

## Building from Source
```bash
git clone https://github.com/doodaddude/Phonebar-for-mac.git
cd Phonebar-for-mac
./scripts/package_release.sh
```
